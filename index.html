Selected work

Intrusion detection

Statistical modelling in R, solo project

R, logistic regression, VIF diagnostics, ROC analysis

I analysed more than 123,000 network records to tell attack traffic from normal traffic across TCP, UDP, and ICMP. I fixed severe multicollinearity and class imbalance, then tuned the decision threshold so the model misses as few attacks as possible.

The model reached an AUC of 0.9937 and an F1 near 98%. Moving the threshold from 0.5 to 0.3 raised attack detection to 98.34%. Drag the line to see what that choice trades away.

The curves are synthetic scores that illustrate the trade-off. On the real data, attack detection was 98.34% at a threshold of 0.3.

DemandFlow

End-to-end data platform

PostgreSQL, ClickHouse, Airflow, FastAPI, React and TypeScript, LLM/RAG, Docker, Kubernetes

A pipeline that extracts demand data, validates it, and only then loads it, so bad rows are stopped before anyone builds on them. Around the pipeline sit a FastAPI service, a React dashboard, and an LLM/RAG layer for asking questions about the data.

An illustration of the validate-before-load idea.
